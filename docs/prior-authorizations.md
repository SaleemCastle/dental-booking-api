# Prior authorizations

Prior authorizations are manual-first clinic records, not insurer API transactions. A local `request_identifier` is generated by the clinic. `POST .../requests` records that staff sent a request and captures channel and provenance; it is not proof the insurer received it. Staff must explicitly record an acknowledgment, request for more information, or decision.

## API

All paths are under `/api/patients/{patient}/insurance-prior-authorizations` and use Sanctum, the current tenant, patient scope, and the standard API envelope.

| Method and path | Permission | Purpose |
|---|---|---|
| `POST /` | `insurance_prior_authorizations.manage` | Create a draft. Requires `Idempotency-Key`, association, request date, treatment details, amount, and currency. Policy revision, claim, plan item, and estimate are optional. |
| `GET /` | `.view` | Paginated list; optional status filter. |
| `GET /{authorization}` | `.view` | Retrieve request, decisions, and events. Encrypted insurer references are not returned. |
| `PATCH /{authorization}` | `.manage` | Update a draft with `expected_version`. |
| `POST /{authorization}/requests` | `.manage` | Record a clinic-sent request with expected version, channel, and provenance. |
| `POST /{authorization}/decisions` | `.decide` | Append acknowledgment, additional-information request, approval, partial approval, denial, or an explicit correction referencing the latest decision. |
| `POST /{authorization}/claim` | `.manage` | Link a same-patient, same-association claim. Does not change claim state. |
| `POST /{authorization}/cancel` | `.manage` | Cancel draft/requested/pending request with a reason and expected version. |
| `POST /{authorization}/expire` | `.manage` | Record expiry when a decision has an explicit past `valid_through`. |
| `GET /{authorization}/history` | `.view` | Retrieve append-only lifecycle events. |
| `POST /{authorization}/evidence` | `.evidence`, `insurance_documents.view` | Link a clean immutable document version to a typed target; also requires `.manage`. Disabled until the existing insurance evidence link switch is approved. |
| `GET /{authorization}/evidence` | `.view`, `.evidence`, `insurance_documents.view` | Retrieve audited typed evidence references; returns no document content. |

Decision `authorized_amount` and `currency` must be supplied together or both omitted. Omitted means unknown. A decision is staff entered and does not assert direct insurer verification. Prior decisions and evidence links cannot be edited or unlinked; corrections create new events and decision rows.

## Workflow boundary

No authorization action changes estimates, claims, submissions, invoices, invoice lines, payments, patient balances, benefit limits, receivables, remittances, or cash. Financial settlement and insurer integrations are out of scope.
