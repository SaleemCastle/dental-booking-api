## API Testing

Import the [Postman collection](docs/postman/dental-booking.postman_collection.json) and [local environment](docs/postman/local.postman_environment.json). See the [Postman setup guide](docs/postman.md) for authentication, variables, write-safety defaults, and audit requests. The API contract is in [OpenAPI](docs/openapi.yaml).

Tenant resolution, service/policy usage, and queue propagation conventions are documented in the [multi-tenant architecture contract](docs/multi-tenancy.md).

The [dental charting contract](docs/dental-charting.md) defines adult/primary numbering, surface findings, immutable revisions, concurrency, authorization, and audit behavior.

Private patient document uploads, S3 configuration, authorization, retrieval, archive/delete semantics and operational recovery are documented in [patient documents and imaging](docs/patient-documents.md).

The [billing contract](docs/billing.md) documents invoice snapshots, lifecycle, partial payments, idempotent retries, authorization, audits and legacy migration requirements.

The [hosted payment-link contract](docs/payment-links.md) covers the HandyPay adapter, signed webhook and status reconciliation, invoice-controlled checkout amounts, sandbox rollout checks, credential revisions, idempotency, audits and provider limitations.

The [provider availability contract](docs/provider-availability.md) documents weekly working hours, breaks, date exceptions/time off, permissions, and booking/rescheduling enforcement.

The [reporting contract](docs/reporting.md) defines permission-aware appointment, provider, treatment and billing aggregates, date/provider filters, utilization and financial calculations, pagination and the detailed-export strategy.

## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.
